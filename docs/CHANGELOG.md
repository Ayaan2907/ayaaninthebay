# changelog

## 1.0.0 · 2026-09-08

first public version.

- terminal that answers as me, streamed from puter (gpt-4.1) or anthropic, offline fallback from the knowledge file
- `/map`: san francisco at night on a hand-rolled canvas 3d renderer, repos as buildings, github events as vans, real weather and daylight
- `/build`: owner-mode builder that runs my agentos pipeline and publishes to puter, with follow-up edits at the same url
- `/call`: voice call with browser speech recognition and puter text-to-speech, interruptible
- `/activity`: github events, heatmap, repos
- blog from markdown with an action that publishes drafts in my voice
- production server with env validation, per-ip rate limits, security headers, healthcheck, json logs
- railway deploy, ci (check + tests), docs and adrs
